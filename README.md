# Westbridge University Website

A responsive multi-page university website built with HTML and CSS.

## Features

- Responsive university homepage
- About and university history sections
- Academic programs and faculties
- Admissions information
- Campus and student-life sections
- News, events and announcements
- Research and publications sections
- Student, staff and learning portal pages
- Library and academic resources
- Contact and help-centre pages

## Technologies

- HTML5
- CSS3
- Responsive Web Design

## Project Purpose

This project was created as a frontend development project to practice building a large, structured, multi-page website with reusable layouts, navigation and responsive styling.
